# Shopping List

This is a shopping list app created in Flutter that lets users add and remove items. To add new items to the list, simply click on the + icon and a form will load. Enter the item name, quantity, and select a category from the dropdown list. Categories include meat, dairy, fruit, vegetables, etc. Field validations apply for name and quantity: the item name must be between 2-50 characters and the item quantity must be greater than 0. The app also connects to a Firebase-hosted backend, so any changes made locally will also be reflected on the backend to ensure data consistency.
